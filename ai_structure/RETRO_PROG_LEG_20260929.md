## 1. 方法

| 项 | 做法 |
|---|---|
| 采样网格 | `2017-09-01` 起**每 7 天**一个采样点（UTC 00:30），共 **445** 点，覆盖 `2018-03-15 → 2026-09-17` |
| 决策侧无前视 | 每个点 T **只用 `ts + 1h ≤ T`** 的 K 线重跑 `swing_watch.analyse()`——条件组统计同样只来自 ≤T 的历史（当时真能看到的东西）。再组装与 `watch_latest.json` 同构的 dict，调用 `forward_log.prog_direction(7)` |
| 打分 | 真实结果 = 全量数据里 `T + 7 天` 那根 bar 的收盘 vs T 那根 → 涨=`多` / 否则=`空` |
| 环境隔离 | 先快照 CSV 再跑（不与运行中的 cron 抢文件）；结果写 `out/prog_walkforward.csv` |
| 复现 | `walkforward_prog.py`（扫描）→ `walkforward_report.py`（汇总）|

```bash
.venv/bin/python walkforward_prog.py     # 全史约 3.7 分钟
.venv/bin/python walkforward_report.py
WF_START=2026-01-01 .venv/bin/python walkforward_prog.py   # 缩短区间
```

**能证明什么**：连续 9 年的历史里，这套结构判定**连样本内**都区分不出涨跌 ⇒ 信号无信息（证伪）。
**不能证明什么**：样本内命中率高 ⇒ 有 edge。**本文没有任何"有 edge"的结论。**

## 3. 结构性原因（代码位置）

`forward_log.applicable_states(pos)`：

```python
def applicable_states(pos):
    keys = []
    if pos.get("phase") == "up":
        keys += ["move", "days", "up_all"]
    if pos.get("breakout"):
        keys.append("breakout")
    return keys
```

- 下行腿且无突破 → **无适用条件组** → `sides` 为空 → 方向恒 `中性`。
  FORWARD_PROTOCOL §2 自己写过这句：「下行腿无对应条件组 → 恒为中性」。
- `空` 只可能来自某个**适用组**的 `p_up_hi < 0.5`；而上行腿的这些组本身就以看涨为条件，
  所以 9 年里一次都没出现。
- ⇒ **`空` 不是"少见"，是结构上不可达。**

## 4. 对现判据的三条含义

1. **`空` 事件永远不会发生** → `FORWARD_PROTOCOL.md` §4.2 里「空信号的真实基准是 45%，
   所以这样比对空信号偏严」那段是**死代码**：判据实际只跑单边。
2. **「三者一致」实质 ≡ 「AI 说多 且 程序同向」** → 程序那一票是「36% 的时间出声、几乎总是`多`、
   永不说`空`、命中率 54.7% CI 跨 50%」的近似随机票。判据事实上在测 **AI 单腿**。
3. **事件频次被程序卡住**：只有 36% 的时间给方向 ⇒ 每周最多 1 个独立窗口 × 36%
   ⇒ n ≥ 30 会比协议 §4.3 写的「最快约 30 周」**显著更久**（§4.3 已预警"若程序大部分时间为中性，
   会更久甚至永远达不到"，现在有了数字）。

## 5. 边界（别误读）

- **样本内**：条件组就是用这段历史设计的 ⇒ 本文结论只能**证伪**，不能**验证**。
  但「连样本内都区分不出涨跌」意味着样本外更不可能——这正是证伪的价值。
- **不能替代前向门槛**：`FORWARD_PROTOCOL.md` 冻结日明文「本协议只用冻结日之后的前向数据」。
  回溯无论结果如何，都不是实盘依据。
- **AI 识图腿不在本文内**：见 §6。

## 6. AI 识图腿（未做，设计已定）

**必须先做泄漏对照**：喂给 AI 的图上有日期轴、表头时间戳、价位区间，模型很可能是在
**回忆"那个时间之后发生了什么"**，而不是在读形态。

| 版本 | 处理 | 用途 |
|---|---|---|
| 原样版 | 现 `chart_dual.png` | 测「未设防的泄漏」上限 |
| 遮蔽版 | 抹掉所有日期标签与表头时间 | **主判据**（只能靠形态判断） |
| （可选）归一版 | 价格轴也改成百分比/索引 | 最严格 |

- 采样：聚焦 §2.5 那两段（大涨 / 下跌），每段 ~20 点 → 40 点 × 2 版 = **80 次调用**（免费，约 80 分钟）
- 指标：命中率（7 天）+ 遮蔽版与原样版的**差值 = 泄漏量级**
- ⚠️ **泄漏只污染回溯，不污染前向**（前向数据模型没见过）⇒ 回溯结果无论多好都不能替代 30 周。
