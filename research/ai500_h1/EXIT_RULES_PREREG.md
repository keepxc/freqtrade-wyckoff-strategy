# 出场规则三候选 —— 预注册（2026-09-25，判据冻结）

> **冻结声明**：本文件 commit 后，§3 判据（J1–J5）与 §2 臂规格**不得修改**。
> 任何修改必须新建文件、新开分段，并在文中显式说明"旧判据作废"。
> 本实验为**纸面 shadow（不占资金、不改任何 live 策略配置）**。

## 0. 背景与机制依据

`EXIT_RULE_SIM.md`（2026-09-25）的发现：

1. 现行 V3 出场（4h 阴线 / −5% / 48h）在 20 天 ≥80 样本上累计 **−41.0%**、胜率 8%、均持仓 **4.1h**；
   而信号的正收益落在 **+24h/+48h**（前向中位 +7.69%/+14.33%）⇒ **出场周期与信号周期错配**。
2. **"48h → 72h" 为零影响**（配对差 +0.04pp，90% CI [−1.0, +1.1]）——12 笔无一触及上限，**已判死，本实验不再包含该臂**。
3. 去掉 4h 阴线判定（改日线）→ 累计翻正；但**胜率仍 8~17%**（10/12 被 −5% 止损吃掉）⇒ 两条规则**同时在砍尾部**。
4. **取消止损不可接受**：无止损固定 7d 累计 +159.5%，但单笔最差 **−87.6%**（AIN 真实崩盘，已双向交叉验证）。
   放宽到 −10% 反而更差（−20.5%）⇒ 方向是**止损宽度与波动匹配**，不是单纯放宽。

## 1. 三个候选臂（精确规格，参数不可调）

| 臂 | 判定周期 | 止损 | 持仓上限 | 改动说明 |
|---|---|---|---|---|
| **R0**（对照） | 4h 阴线收盘 | 固定 −5% | 48h | 现行 V3 原样（基准） |
| **A** | **日线阴线收盘**（UTC 00:00 收盘） | 固定 −5% | 72h | 单变量：只改判定周期 |
| **B** | 4h 阴线收盘 | **自适应：`min(2 × ATR(4h,14) / 价格, 20%)`** | 72h | 单变量：只改止损宽度（20% 为**风险硬上限**，非调参） |
| **C** | 日线阴线收盘 | 同 B | 72h | A + B 组合 |

- **入场**（四臂完全相同）：score 首破阈值后的**第一个 4h 边界**买入；同一 episode 四臂共用同一入场价 ⇒ **配对数据**。
- **ATR 口径**：入场时刻之前的 14 根 4h K 线的 TR/价格均值（无量纲），只用历史数据，无前视。
- **成本**：费率 0.05%/边 + 滑点 0.05%/边（与 dry-run 同档）；J4 另测双倍档。
- 判定周期出场：该周期收盘为阴线（close < open）即出场，收盘价成交。
- **强制止损保留**（AIN 教训）：所有臂都必须有触发式止损。

## 2. 评估设计与口径

- **形态**：纸面 shadow。每个合格信号记录 **四臂各自的结果**（同一入场）⇒ 配对。
  状态文件：`user_data/ai500_local/exit_arms_signals.csv`（信号与入场）、`exit_arms_results.csv`（各臂结果）。
- **主口径（判决用）**：**≥70 首破**（24h 冷却）——理由：80 门 0.65 个/天，需 90~190 天（不可行）；
  70 门 2.3 个/天，25~53 天可达所需样本。出场规则与入口门正交，配对差即出场效应。
- **辅口径（一致性检查）**：**≥80 首破**子样本；只用来检查"出场效应是否与入口门无关"，**不单独判决**。
- **右侧删失**：窗口未走完的信号标记 `censored`，不计入判决样本。
- **回填**：20 天历史回填结果（见 `EXIT_RULE_SIM.md` / `arms_prereg` 输出）**仅用于假设生成与样本量估算，禁止引用为证据**。

## 3. 判据（冻结）

**判决对象**：每个臂 vs R0（主口径、配对、去删失）。

- **J1（主效应）**：配对**均值差 ≥ +5.0pp**（同一 episode、同一入场的逐笔差）。
- **J2（对半切稳健）**：前向样本按时间对半，两半的配对均值差**符号相同**。
- **J3（跨标的一致性）**：至少 **3 个不同标的** 的配对均值差 ≥ 0，且 ≥ 60% 的标的上同号。
- **J4（成本档）**：双倍成本（费率 0.1%/边、滑点 0.2%/边）下配对均值差 **≥ 0**（不反号）。
- **J5（风险闸·可否决）**：①单笔最差不得劣于 R0 超过 **10pp**；②**任何一笔 ≤ −30% 即整臂否决**（归零风险）；
  ③等权净值 MaxDD 不得比 R0 恶化 **> 5pp**。
- **附加 fail-safe**：AIN 类崩盘样本（09-16 AIN −87%）必须被该臂的止损/判定规则捕获（不允许 −50% 以上单笔）。

**判决规则**：J1–J5 全过 = 该臂通过。**允许多臂同时通过**；若多臂通过，选 **MaxDD 更小者**；
仍并列 → 选**改动更小者**（优先级 A > B > C）。
**弃案规则**：主口径累计到 **n = 70 个配对信号**仍未过 J1 → 该臂判负，不再加样本。

## 4. 样本量与工期（含 MDE）

| 臂 | 回填配对均值差 | sd(配对) | 80% 功效所需 n | 主口径(70门)工期 | 80门工期（不可行，仅记录） |
|---|---|---|---|---|---|
| A（日线判定） | +6.08pp | 20.49pp | **70** | **≈30 天** | ≈108 天 |
| B（自适应止损） | +1.53pp | 6.81pp | **123** | **≈53 天** | ≈189 天 |
| C（A+B） | +11.24pp | 34.52pp | **58** | **≈25 天** | ≈90 天 |

- 功效公式：`n ≈ (1.645+0.84)² · sd² / Δ²`（单侧 5%、80% 功效、配对均值检验）。
- **MDE 提示**：以 n=70 计，A 臂可判定的最小效应 ≈ **+6.0pp**；更小的效应本实验**判不出**（不得写成"无效应"）。
- 回填只是**真值假设**：若真实效应小于回填值，所需样本按 (Δ回填/Δ真实)² 放大。

## 6. 部署路径（通过之后）

1. 通过 = **仅证明"纸面配对差"**，不等于可直接上线。
2. 若某臂通过：新建 **V4 实盘臂预注册**（复制本文件 §3 判据 + live 执行细节），
   `shadow` 与 `live` 并行一段，确认纸面→实盘无系统性偏差后再切换。
3. **禁止**：看结果中途改臂规格、改 J 阈值、改口径；也禁止把回填结果当证据。

## 7. 已知局限（写在前头，避免事后辩解）

- 回填 n=13（主口径前向从本文件 commit 时刻起算），含死相位样本，同标的可能重复出现。
- 15m K 线近似盘中触发；真实滑点分布未建模（J4 用双倍成本近似）。
- AIN 类 −87% 崩盘是**真实事件**，会主导任何"无止损/宽止损"臂的尾部——这正是 J5 存在的理由。
- 主口径换成 70 门是**功效驱动的口径选择**；若 70 门与 80 门的出场效应存在实质差异，J3/辅口径会暴露它。
