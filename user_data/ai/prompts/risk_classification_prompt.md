# P5 V1-C-4：AI 风险分级规则

> 适用场景：AI 在完成显著性判断和归因分析后，必须给出风险等级（L1-L4），并映射到具体行动指令。

---

## 风险等级定义

### L1：统计波动 — 无需动作

**触发条件（全部满足才能定 L1）**：
- 胜率波动在 ±8% 以内（相对基线）
- 平均 PnL 波动在 ±0.5% 以内
- 样本量 < 30 笔
- 无 detector / regime 明显异常
- 已有归因解释为"统计噪声"

**建议行动**：
- ✅ 继续正常运行
- ✅ 继续积累观察数据
- ❌ 禁止修改任何参数

---

### L2：持续观察 — 不立即动作，设定触发条件

**触发条件（满足任意一项）**：
- 胜率连续 2 周低于 45%（样本 5~29 笔）
- enter_tag 单个 drift > 15%（样本 5~29 笔）
- bear_market_mode 单周占比 30-50%
- 某 detector 激活率偏离基线 > 30%（但样本不足）

**建议行动**：
- ✅ 持续观察，每周更新报告
- ✅ 设定下一个触发条件（如"再观察 2 周"或"等到 N 笔"）
- ✅ 可以准备（但不提交）候选提案
- ❌ 禁止进入正式实验

---

### L3：建议进入最小实验矩阵

**触发条件（全部满足）**：
- 样本量 ≥ 30 笔（相关 enter_tag 或总体）
- 有明确的归因结论（Layer B：局部信号问题）
- 归因在 2 个以上时间段或数据集中一致
- 影响范围可控（局部，非全局退化）

**建议行动**：
- ✅ 生成正式 AI Proposal（参考 V2-2 格式）
- ✅ 进入实验矩阵评审
- ✅ 设计最小可测试的参数变更
- ❌ 禁止跳过回测直接上 Dry Run

---

### L4：建议暂停晋升 / 回滚 / 人工审查

**触发条件（满足任意一项）**：
- 全局胜率连续下滑 3 周以上，任何样本量
- 多维指标同时恶化（频率 + 胜率 + 盈亏比）
- 发现 Detector 逻辑 Bug（如激活率归零或恒为 1）
- bear_market_mode 占比 > 80% 且 P2 条件未跟进
- 已有 candidate 实验结果显著差于 baseline

**建议行动**：
- ✅ 立即暂停当前 candidate 晋升为 baseline
- ✅ 考虑回滚至上一个稳定 baseline（如果处于 candidate 阶段）
- ✅ 触发人工审查（通知操作者）
- ✅ 锁定当前参数，等人工确认后再恢复操作
- ❌ 禁止 AI 自动修改任何参数

---

## 风险等级判断流程

```
开始
  ↓
归因分析类型？
├── A（统计噪声）→ L1
├── B（局部信号，样本 < 30）→ L2
├── B（局部信号，样本 ≥ 30，跨阶段一致）→ L3
├── C（Regime 变化）→ 视严重程度：L2 或 L3
└── D（全局退化）→ L4

特殊强制升级规则：
- 任何情况下，若连续 3 周胜率 < 40% → 直接 L4
- 任何情况下，若 Detector Bug 确认 → 直接 L4
- 任何情况下，样本 < 5 笔 → 维持 L1，禁止升级
```

---

## Prompt 前缀（嵌入到分析末尾）

```
在完成归因分析后，必须给出标准化风险分级：

【风险分级】
- **风险等级**：[L1 / L2 / L3 / L4]
- **定级依据**：[1-2 句说明为什么是这个等级]
- **建议行动**：[对应等级的行动列表]
- **解锁条件**（仅 L2）：[需要满足什么条件才升为 L3/L4]
- **紧急程度**：[低（继续观察）/ 中（下次周期处理）/ 高（立即处理）]
```

## 与其他模板的关系

| 模板 | 用途 | 与风险分级的关系 |
|------|------|----------------|
| `weekly_report_prompt.md` | 读周报 | 健康度评估是 L1/L2 的前置输入 |
| `significance_check_prompt.md` | 显著性检查 | 样本量决定 L1/L2/L3 的可达性 |
| `attribution_analysis_prompt.md` | 归因分析 | 归因类型 A/B/C/D 直接映射风险等级 |
| `proposal_generation_prompt.md` | 生成提案 | 仅 L3/L4 才允许触发提案生成 |
