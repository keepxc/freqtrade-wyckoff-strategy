# P5 V1-C-2：AI 显著性判断模板

> 适用场景：AI 在分析任何绩效数据时，必须先经过本模板的显著性判断，**禁止在不满足门槛时给出调参建议**。

---

## Prompt 前缀（嵌入到分析任务前）

```
在进行任何性能分析之前，请先执行以下显著性检查，并在输出中明确声明结果。

【显著性判断规则】

Step 1：确认样本量
- 已平仓交易数 < 5：→ 极小样本，终止分析，输出"样本极少，无法诊断"
- 已平仓交易数 5~29：→ 小样本，分析仅供参考，禁止直接调参
- 已平仓交易数 30~99：→ 低门槛通过，可以识别问题，但建议多周期验证
- 已平仓交易数 ≥ 100：→ 显著性样本，结论有统计意义

Step 2：检查跨阶段一致性
- 多时段数据是否一致（不同周/月趋势是否吻合）？
- 是否只有一段时间表现异常？
- 跨阶段不一致 → 降低置信度，标注为"噪声候选"

Step 3：排除市场环境解释
- 当前 bear_market_mode 是否偏高（>50%）？
- 当前 regime 是否与历史基线差异显著？
- 如果市场环境异常 → 表现异常可能是环境变化，非参数问题

Step 4：输出显著性声明

必须在分析开头以如下格式声明：

【显著性声明】
- 样本量：[N 笔已平仓交易]
- 样本级别：[极小样本 / 小样本 / 低门槛 / 显著性]
- 跨阶段一致性：[一致 / 不一致 / 无法判断]
- 市场环境是否异常：[是（原因）/ 否]
- **分析可信度**：[高 / 中 / 低 / 无法分析]
- **是否允许提案调参**：[是 / 否（原因）]
```

---

## 门槛速查表

| 样本量 | 级别 | 允许操作 |
|--------|------|--------|
| < 5 | 极小样本 | 禁止所有分析结论 |
| 5–29 | 小样本 | 仅观察，禁止调参提案 |
| 30–99 | 低门槛通过 | 可识别问题，建议多周期验证 |
| ≥ 100 | 显著性通过 | 允许提案，需通过风险分级 |

---

## 注意事项

- 显著性声明是**强制步骤**，不可省略
- 若 AI 输出中缺少显著性声明，视为无效分析
- 样本量以**已平仓交易数**（`exit_time IS NOT NULL`）为准，候选信号数不计入
- 单个 enter_tag 独立计算样本量（如 `wyckoff_spring` 只有 3 笔，即使总交易 50 笔也视为小样本）
- 当 bear_market_mode 高占比时，优先排查 P2 regime 条件，而非调整信号参数
