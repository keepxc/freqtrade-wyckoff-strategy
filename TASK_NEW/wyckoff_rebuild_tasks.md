## 0. 本次重建的前提

### 0.1 与既有 TASK 记录的关系

`quant_system_tasks.md` 中围绕威科夫 V8/V9 的历史结论，**在本次重建中一律降级为"线索"，不作为定论引用**。理由不是赌气推翻，而是两条可验证的事实：

1. **审计脚本本身会错，且错误会生产出错误的结论。** 已有实证：TASK 102 的 L4 判据把 `MAX_LEV`（封顶）当作实际杠杆代入，而机制实为 `min(MAX_LEV, TARGET_VOL/vol)`，导致该 TASK 被误判为 ❌ 证伪并关闭（2026-07-26 修正为 ⭕）。既然审计层可能有缺陷，则所有**仅由审计脚本支撑**的结论，其可信度不高于该脚本的正确性。
2. **多数旧结论的样本量本就不足以支撑强判断。** 威科夫事件是低频结构性事件，历史 TASK 中大量结论建立在几十笔、甚至个位数样本上。

**降级规则**：
- 旧结论中属于**代码事实/机制事实**的（可复现、可定位）→ **保留为事实**。例：V8 的 ZigZag 回溯标记确为未来函数，修复后收益从 75,687% 降至 17,360%；Donchian 20/10 状态机为纯因果实现。
- 旧结论中属于**统计判断**的（"X 有效/无效"）→ **降为线索**，既不引用它支持新方向，也不用它否定新方向。

### 0.2 本次重建要解决的核心问题

V8 的失败不是威科夫理论的失败，而是**威科夫的语言天生是回溯性的**这件事没有被工程手段防住。

Spring、Test、SOS、LPS 的定义都依赖"后来发生了什么"——"这根低点是 Spring"只有在价格收回之后才成立。人看图时这是天经地义的；直译成代码时，它就是未来函数的定义式。V8 的 ZigZag 回溯标记不是疏忽的 bug，是**把威科夫直译成代码的必然产物**。

因此本次重建的第一步不是写策略，是**先建立能机械检出这类缺陷的工具**。

## 1. 设计原则（本次重建专用，叠加于 CLAUDE.md 之上）

### 原则 W-A：指标发布即不可变（append-only）

任何指标一旦在 bar `t` 被计算出来，**不允许被 `t` 之后的数据改写**。形式化为：

```
∀ t, ∀ 列 c:   populate_indicators(data[:t+1])[c].iloc[t]
             == populate_indicators(data[全量])[c].iloc[t]
```

这条不变量是机械可测的（见 W0），不依赖人眼 Code Review。ZigZag 回溯标记会立刻违反它：全量数据下 `is_wave_start[t]=True`，截断到 `t` 时为 `False`（转折尚未确认）。

**推论**：每个威科夫事件必须写成"**事件 + 确认延迟**"的形式——不是"这里是 Spring"，而是"**截至今日收盘，过去第 k 根 bar 满足 Spring 的全部条件**"。延迟 `k` 是显式策略参数，需被回测与检验，禁止隐藏在实现细节中。

### 原则 W-B：审计脚本与策略代码同等门控

零原则（Code Review 前置）**扩展适用于审计/探索脚本**。理由见 0.1 第 1 条。具体要求：
- 审计脚本中每一条判据的**算式**必须与被测机制逐项对齐，写明"本判据测的是机制里的哪个量"
- 判据涉及策略内部量（杠杆、仓位、止损距离）时，必须用**机制真实值**，不得用参数上限/名义值替代

### 原则 W-C：单元化，不建大教堂

V8 是耦合系统（Phase 判定 + TR 结构 + PNF 目标 + 多档止损 + 多条 enter_tag 路径），任一环节出错即污染全部结论，且无法定位；488 笔交易分散在 5-6 条路径上，每条路径样本量都不足以说明问题。

本次**一次只做一个威科夫命题，独立成信号，独立回测，独立判定**。禁止在前一个单元判定完成前开始下一个。

### 原则 W-D：每个条件都要有对照组

每加一个威科夫条件（缩量、不创新低、突破确认……），必须同时跑一个**去掉该条件**的对照组，用以隔离该条件本身的增量贡献。否则无法区分"是威科夫在起作用"还是"是那个 N 日新低在起作用"。

### 原则 W-E：基准是 DonchianV1，且必须是替代而非叠加

- **基准**：`DonchianV1`（已封版，git tag `donchian-v1-sealed`）。同窗口、同成本口径（0.11%/边）、同固定仓位、同三层校验。
- **必须是独立策略，不得设计为 Donchian 的增强/过滤层。** 依据：TASK 100/101/103/106 四次不同方向的叠加尝试全部为 ⭕，该位置已无空间（此处引用的是"叠加位置反复无增量"这一模式，属线索级，但足以作为设计选择的理由）。
- 核心问题只有一个：**一个复杂的、有理论叙事的结构性系统，能否打赢一个连"趋势"都不认识的 20/10 通道突破？** 打不赢即停止，不是"再调参数"。

### 原则 W-F：先算功效，再跑回测

任何单元在跑回测**之前**，先回答：以该单元的预期事件频率与合理效应量，当前样本量能否检测出该效应？若答案是"需要 15% 的 per-trade 优势才显著、而合理预期是 2-3%"，则该实验**从设计上就不可能给出结论**，应改设计（换更长历史 / 换时间框架）而非跑完再纠结 CI 是否跨零。

## 3. 执行路线

### W0：截断复算测试框架 ✅

**目标**：实现原则 W-A 的机械检测工具。不碰任何策略文件。

**规格**：
- 输入：一个 `populate_indicators`-like 的纯函数 `f(df) -> df`，以及数据集
- 随机抽样 K 个时点 `t`（K 可配，默认 200；含刻意抽取的高波动/转折时点）
- 对每个 `t`：`f(df[:t+1]).iloc[t]` 与 `f(df).iloc[t]` 逐列比对
- 输出：违反不变量的列名、首次违反的时点、违反幅度；以及每列的"稳定所需延迟"（截断到 `t+d` 时该列 `t` 处的值不再变化的最小 `d`）——这个 `d` 直接给出原则 W-A 要求的确认延迟下界
- 数值比较用容差（浮点），NaN 与 NaN 视为相等

**四个关键设计决定**：

1. **只比 `.iloc[t]`，但每个 t 用它自己的截断**。整段前缀比对会让一个回溯标记在所有 t 上刷屏、淹没定位；逐 t 截断则报出的位置精确指向出问题的那一根 bar。
2. **抽样必须分层**。威科夫事件稀疏（3000 根日线可能仅 ~40 个 Spring），而未来函数只在事件 bar 上暴露（非事件 bar 两边都是 False，怎么截断都相等）。均匀随机抽样会大概率全绿通过并给出**虚假安全感**。故布尔/事件列全量 True 的 bar 一个不漏地纳入，再以高波动时点与随机点补足。
3. **顺带测出确认延迟 d**：截断点后推，找最小的 d 使 `f(df[:t+1+d]).iloc[t]` 此后不变。d 即该列确认延迟的下界，直接回答"shift 几根"（V8 的 `shift(3)` 是拍出来的，事后证明补偿不足）。
4. **验收双向**：只测通过项证明不了检出能力，阳性/阴性对照缺一不可。另需先验 f 自身确定性（连跑两次须逐字节相同），否则一切"违反"都是噪声。

**实现**：`user_data/scripts/lookahead_truncation_test.py`（自检输出 `w0_selftest_out.txt`）

**执行过程中的两次自我修正（如实记录，均为实现阶段发现）**：

- **修正 1（有效）**：违反判定由"只比 `t+1` 与全量两个点"改为**沿截断长度阶梯** `d ∈ {0,1,2,3,5,8,13,21,34}∩[0,d_max]` 逐个比对，任一不等即判违反。防"值随截断点后推非单调变化"的漏检。
- **修正 2（推翻我自己的错误诊断）**：首版自检时，阴性对照的检出方向与预测相反（预测「截断=False/全量=True，d≈5」，实测全是「截断=True/全量=False，d=1~2」）。我一度将其归因为工具漏检"粘性未来函数"，**该诊断是错的**——推导可知：对 `min over [i-5,i+5]` 型定义，真 pivot 在截断时窗口变小、仍是最小值，故两边相等本就不违反；而 V8 那种延迟确认后回溯置位的粘性标记，在 `d=0` 时即为 False vs True，首版就抓得到。**真实原因是两种不同形态的未来函数签名本就不同**，不是工具缺陷。据此补充了第三个对照（见下），而非"修复"一个不存在的 bug。

**验收结果（全部 PASS）**：

| 对照 | 未来函数形态 | 违反签名 | 确认延迟 d |
|---|---|---|---|
| 阳性 | 无（`DonchianV1` 因果实现：通道 + vol-target 波动率） | **无违反**（235 抽样点 × 4 列） | — |
| 阴性 1 | 窗口型 `min over [i-5, i+5]` | 截断=True / 全量=False，16 处 | 1~2 |
| 阴性 2 | **粘性回溯标记（V8 ZigZag 形态）**：bar i 确认后回溯把 i-5 置 True | 截断=False / 全量=True，**183/183 处方向一致** | **恒为 5** |

阴性 2 的 d 精确等于复现中植入的 `LAG=5`，证明 d 的测量可直接用作确认延迟参数，无需拍脑袋。

**结论**：W0 完成。工具不误报（阳性全绿），且对两种不同形态的未来函数均有检出力（两个阴性对照均报出，签名与理论预测一致）。

**状态**：✅ 完成（2026-07-26）

### W1-c：Spring/Test 信号有效性检验（**预注册，判据冻结，未跑数**，2026-07-26）

**立项依据（第一原则合规）**：W1-a 确认该定义满足 append-only 不变量（可实盘复现）；W1-b 确认在市场中性口径 + 15 币种宇宙下 MDE=2.52%，落入威科夫合理效应量范围，实验具备给出结论的功效。二者均在本 TASK 跑任何收益数字之前完成。

**范围限定**：只检验 Spring/Test 事件的**事件后收益特征**，不构建策略、不涉及仓位/止损/退出、不与 DonchianV1 做策略级比较（那属于 W1 通过后的独立步骤）。

**数据**：15 个 Binance USDT 永续日线（ADA/ATOM/AVAX/BCH/BNB/BTC/DOGE/DOT/ETC/ETH/LINK/LTC/SOL/TRX/XRP），宇宙规则已于 W1-b 冻结。**幸存者偏差如实标注**：该列表为存活至 2026 年的品种，非点位时间宇宙，已退市/归零者不在其中——此为结构性局限，无法通过方法修正，本 TASK 全部结论均带此前提。

**构造（冻结，禁止跑数后增删）**：
- 事件定义与参数逐字沿用 `explore_spring_test.py`：`N_CLIMAX=20 / T_WINDOW=15 / TOL=0.03 / VOL_TEST_RATIO=0.7 / T_CONFIRM=5`，禁止调参
- 主定义 = 要求缩量测试；对照定义 = 不要求缩量（原则 W-D，用于隔离"缩量"条件本身的贡献）
- 主口径 = **市场中性 fwd10**：`ret_mn[i,t] = fwd10[i,t] - mean_j(fwd10[j,t])`
- 报告级口径 = 原始 fwd10、原始 fwd20、市场中性 fwd20（**均功效不足，只报告不判定**）
- 统计方法 = 按日期区块的跨资产联合自举，`block=20`、`n_boot=2000`、`seed=20260726`（与 W1-b 同源）

**预注册判据（冻结）**：
- **P1 方向性**：主定义事件组市场中性 fwd10 均值的自举 90% CI **下界 > 0**
- **P2 效应量下限**：该均值点估计 **≥ +2.0%**（低于此即便 CI 不跨零也属噪声级，与 CLAUDE.md 三档分级的 2% 门槛一致）
- **P3 缩量条件有贡献（W-D 对照）**：`主定义均值 − 对照定义均值` 的自举 90% CI **下界 > 0**。若 P3 不过但 P1+P2 过，则结论为"结构性二次探底有效、但缩量条件无增量"，须据实写明，不得含糊为"Spring 有效"
- **P4 时间稳健性**：以事件日期中位数切分前后两段，两段主定义均值**同号**
- **P5（一票否决）**：若主定义事件数 < 200（低于 W1-b 功效分析所依据的 258 的 80%），判定功效前提失效，本次不得下结论

**判定映射**：

### W2-a：失败突破（Failed Breakout）信号有效性检验 ⭕（不采纳，2026-07-26）

**命名更正（重要，先于一切）**：摸底脚本中此项标为"UTAD 假突破"，**该命名不准确**。威科夫原义的 UTAD（Upthrust After Distribution）要求处在**派发区间的语境**中，而本定义只是裸的"突破失败"，无任何区间/阶段前置条件。**本 TASK 检验的是"失败突破"这一价格行为命题，不是 UTAD，也不应被视为对威科夫 UTAD 理论的检验。** 若不作此更正，无论结果如何都会被错误归因到威科夫理论头上。

**立项依据（第一原则合规）**：W2 摸底确认该定义通过 W0 因果检查、事件数 1836、MDE=1.04%、单币集中度 9.0%，且机制独立于 Donchian（为其补集）。以上全部在跑任何收益数字之前完成。

**范围限定**：只检验事件后收益特征，不构建策略、不涉及仓位/止损/退出、不与 DonchianV1 做策略级比较。
