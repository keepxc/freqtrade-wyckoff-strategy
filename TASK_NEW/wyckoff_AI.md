## 0. 核心转向（v1 → v2）

v1 设计的是**全量在线 RL**（PPO + LSTM 重写整个策略）。经两轮论证 + 一次实验，**否决该方向**，转为**监督式离线质量模型**。

转向的两条依据：

**依据 A — BC 实验证明"形态可学"，但只证明了地基，没证明 edge**

`bc_entry_learnable.py` 结果（2026-06-26，测试集样本外）：

| 入场路径 | 样本数 | AUC | 解读 |
|---|---|---|---|
| 整体 | 323 正 | **0.774** | 仅凭 48 根 OHLCV 形态即可预测 V8 入场 |
| `v8_ws_d`（Phase D 多头） | 12 | 0.873 | 最强（样本少，参考） |
| `v8_ws_e`（Phase E 多头） | 175 | **0.843** | 多头形态高度可学 |
| `v8_short_wsdown`（空头） | 126 | **0.684** | 空头依赖结构规则，形态信号弱 |

**关键推论**：
1. [COMPUTED, HIGH] OHLCV 形态里有真实信号 → ML 路径有地基
2. [COMPUTED, HIGH] **ML 的 edge 在多头侧，不在空头**。我们前 6 轮实验一直在啃的 wsdown（0.684）恰恰是形态信号最弱的路径——这解释了为什么"量价结构替代时间代理"在 wsdown 上反复失败：wsdown 的 edge 本就更多来自结构规则（DCS/rolling 24h），不是 K 线形态
3. [INFERRED, HIGH] **BC 的天花板是 V8 自身**。模仿 V8 ≠ 超过 V8。实验没有回答"ML 能否做出比 V8 更好的决策"——这是真正的 edge 问题，见 §3

**依据 B — 在线 RL 的致命问题，BC 实验一个都没解决**（见 §1，保留以防重新论证）

## 1. 为什么否决"全量在线 RL"（已固化，不重新论证）

| # | 致命问题 | 性质 |
|---|---|---|
| 1 | **解决的是不存在的问题**：起点只是想替换 `rolling(24h)` 一个时间代理，而它本就有效。推倒 9.35M% 已验证 edge 去换一个大概率跑不赢的架构，是 motivation 错误 | 前提错误 |
| 2 | **Reward shaping 把手写规则原封搬回**：`bars_held>72`、`drawdown>0.03`、`-0.002/+0.01` 都是魔法常数，`bars_held>72` 本身就是另一个时间代理。没消除规则，只是挪到更难调试的地方 | 自相矛盾 |
| 3 | **非平稳性**：MDP 假设状态转移平稳，市场不满足。2022 熊市学到的最优策略对 2026 无理论保证。这是 RL 交易样本外崩溃的根本理论原因，非数据量能补 | 理论硬伤 |
| 4 | **有效样本量是 regime 数，不是 bar 数**：4 年仅 ~3-4 个独立 regime。数据增强只在已有 regime 内插值，不创造新 regime 信息 | 数据硬伤 |
| 5 | **Episode 切断复利链**：V8 的 9.35M% 来自满仓连续复利（max_open_trades=1）。随机 720-bar episode 让智能体永远体验不到长期复利动态，`new_equity_high` 退化为局部高点 | 机制摧毁 |
| 6 | **缺仓位/杠杆/funding/成本建模**：Action 只有方向没有 sizing，无法复制 V8 的满仓复利机制；永续 funding 未建模 → 学到现实不存在的盈利；RL 会无情套利回测的完美成交假设 | 工程缺失 |

> 结论：在线 RL 不是当前问题的解。若未来重新评估，只考虑**离线 RL**（§4），不考虑在线探索。

## 2. 新主路径 — 监督式入场质量模型（离线，从 V8 日志学）

### 定位

```
Wyckoff 结构门控（V8 保持不变，提供候选信号 + 结构特征）
        ↓
监督式质量模型（新增）：对每个候选打分 entry_quality
        ↓
score > threshold → 入场
```

模型**不替换** V8 的任何规则，只在 V8 已触发的候选上加一层质量判断。V8 是 expert，模型学的是"在 V8 候选中，哪些值得做"。

### 切入点：多头优先（数据决定，非直觉）

- 第一目标：`v8_ws_e` / `v8_ws_d`（AUC 0.84+，形态信号最强）
- **暂不碰 wsdown**（AUC 0.684，形态弱，edge 在结构规则里，ML 增益空间小）

### 特征（三层，与 v1 一致但用于监督而非 RL state）

```
层1 原始序列：最近 48 根 bar OHLCV，归一化到当前 close（240 维）
层2 Wyckoff 结构上下文：dcs / phase / wave_displacement / sm_v2 / be / tr_exists（连续值）
层3 候选元信息：enter_tag one-hot、入场相对 EMA200 位置
```

### 模型

```
第一步：LightGBM（表格 + 序列展平，可解释，feature importance 验证学到什么）
第二步（若有效）：1D-CNN over 48-bar 序列，学真正的序列形态
```

## 3. Filter value 实验结论（2026-06-26，已完成）✅→❌

`audit_effort_vs_result.py`，对象：多头入场 467 笔（ws_e 441 + ws_d 26），标签：forward MAE 24h。

**结果**：

| 模型 | AUC | 判定 |
|---|---|---|
| Logistic Regression | 0.631 | ⚠️ 弱信号 |
| Gradient Boosting | 0.567 | ❌ 无信号 |

**表面结论**：弱信号区间，不满足 AUC > 0.65 的继续条件。

**但真正的结论比 AUC 更根本——标签本身就是错的**：

```
MAE 中位数 = -0.81%
100% 的多头入场，24h 内都存在负 MAE（最低价必然低于入场价）
69% 的入场，24h 内最大回撤超过 -0.5%

MAE vs profit 相关系数 = 0.23（< 0.3，MAE 不是 profit 的有效代理）
```

V8 多头是"先回调再上涨"的结构——入场后短期回撤是正常摩擦，不是"坏入场"。
用 MAE 区分好坏，在这个交易模式下信噪比从根本上就低。

**数据对比**（证明"被证伪"笔仍然盈利）：

| 分层 | 笔数 | profit 均值 | WR |
|---|---|---|---|
| MAE < -1%（"坏入场"） | 191 | +1.96% | **90.6%** |
| MAE ≥ -0.5%（"好入场"） | 145 | +3.81% | 99.3% |

"坏入场"WR 仍有 90.6%，说明 V8 的多头门控已经足够严格，**没有劣质入场可过滤**。

**结论**：[COMPUTED, HIGH] **多头路径不需要 ML filter**。V8 的 Wyckoff 结构门控已经把多头入场质量做到极限，ML 在这里找不到增益空间。Recall value（捕捉 V8 漏掉的好入场）是唯一剩余方向，但需要先证明 V8 确实遗漏了有价值的机会——这本身需要新的实验设计（见 §3b）。

## 3b. Recall value — 唯一剩余的 ML edge 方向（未做）

Filter 已证伪。唯一剩余问题：**V8 规则漏掉的机会里，有没有 ML 可以捕捉的 edge？**

验证方法：
1. 找出所有"V8 结构条件**接近**满足但未触发"的 bar（候选池）
2. 对这些 bar 计算 forward return（24-48h）
3. 检验：这些 bar 的 forward return 分布是否和 V8 实际入场相近？
   - 相近 → V8 存在漏网之鱼，ML 有召回价值
   - 显著差 → V8 的门控是有效鉴别器，漏掉的就是该漏掉的

**门控条件**：在做此实验前，先回答：
> V8 在当前 timerange 内有多少"接近触发但未触发"的候选？如果候选池 < 100 个，recall 实验无统计意义。

## 4. RL 降级为后期窄范围选项（门控在 §3b 之后）

仅当 §2/§3 证明监督模型有 filter/recall 价值后，才考虑：

- **离线 RL（CQL/IQL）**：在 V8 的 700+ 笔固定日志上学，无在线探索，避开非平稳探索与 simulator 套利
- **窄范围 RL**：只学**一个**子决策（仓位 sizing 或退出时机），状态/动作空间小一个数量级，数据够用，V8 结构逻辑全保留

全量在线 RL 永久排除（§1）。

## 5. 诚实的 caveats（不得忽略）

| caveat | 说明 |
|---|---|
| **AUC 在重采样分布上测的** | BC 实验用 5% 负采样（正样本率 24.6%），真实 base rate ~1.6%。AUC 阈值无关相对稳健，但"85% 精确率"是重采样下的，真实 base rate 下精确率会低得多 |
| **regime 自相关可能虚高 AUC** | 部分 AUC 可能来自"当前处于什么 regime"的自相关，而非纯形态。需在 filter 实验中用 regime 内对比剥离 |
| **非平稳性对监督模型同样存在** | 比 RL 轻（监督有固定标签，不需探索），但 walk-forward 仍必须严格、final test 绝不在开发期窥视 |
| **多头小样本** | ws_d 仅 26 笔、ws_e 441 笔。filter 实验需关注样本量是否支撑结论（>30 笔门槛） |

## 7. 当前最诚实的状态评估

两轮实验后，**ML 增强 WyckoffV8 的路径比预期难得多**：

- **多头**：V8 门控已经很严格，没有劣质入场可以过滤（WR 90-99%）。ML filter 无用武之地。
- **空头 wsdown**：形态信号弱（AUC 0.684），edge 来自结构规则，不是 K 线形态。ML 难以增益。
- **唯一未探索**：Recall value——V8 是否遗漏了有价值的机会？

如果 §3b 的 Recall 实验也证伪，**正确结论是：WyckoffV8 的 edge 来自精确的领域知识编码，ML 在当前数据规模下无法超越它**。这不是失败，这是对系统质量的最高肯定。

## 8. 相关文献：arXiv 2403.18839

> Jai Pal, *Long Short-Term Memory Pattern Recognition in Currency Trading*, 2024-02
> [https://arxiv.org/abs/2403.18839](https://arxiv.org/abs/2403.18839)

### 论文核心做法

**目标**：用 LSTM + CNN 识别威科夫积累形态（Trading Range、Secondary Test 等子结构），而非识别具体入场 bar。

**架构**：
- CNN：识别 K 线空间形态（单 bar 或小窗口的视觉结构）
- LSTM：识别跨 bar 的时序依赖（结构展开的时序叙事）
- 两者并联或串联处理同一序列

**训练数据构造（关键）**：
- 正样本：手工标注的威科夫结构位置（摆点，swing points）
- 负样本：填充点（filler points），引入噪声，防止过拟合特定形状
- 标签粒度：**结构级别**（这段市场是 Phase B / Phase C），不是 bar 级别

**结论**：LSTM/CNN 能有效检测威科夫形态，精度显著优于传统规则识别。

---

### 对本项目的启示

论文揭示了我们两轮实验**失败的根本原因**：

| 维度 | 我们的做法（失败） | 论文的做法 |
|---|---|---|
| 标签粒度 | bar 级别（这根 bar 要不要入场） | 结构级别（这段市场处于哪个 Wyckoff Phase） |
| 标签来源 | V8 入场时间戳 | 手工标注的结构转折点 |
| 信息密度 | 低（单点事件） | 高（持续数天/数周的结构状态） |
| 学习难度 | 极高（单 bar 噪声大） | 较低（结构在序列层面有持续性） |

**结论**：我们一直在问错误的问题。问"哪根 bar 入场"是一个极低信噪比的问题；正确的问题是"**当前市场处于哪个威科夫结构阶段**"——这是一个信息持续时间更长、ML 更容易学习的问题。

### 新方向：结构级别 Phase 检测（§3c）

基于论文启示，提出第三条 ML edge 方向：

**预测目标**：当前 bar 处于哪个 Wyckoff Phase（而非"是否入场"）

```
输入：过去 N 根 1H bar 的 OHLCV 序列（CNN+LSTM 双路）
输出：Phase 标签（accumulation_B / accumulation_C / accumulation_D /
                  accumulation_E / distribution_X / markup / markdown）
```

**标签来源**：V8 已计算每根 bar 的 `phase_tag` + `dcs_active` + `sm_v2`——**不需要手工标注**，直接从 `populate_indicators` 输出导出。这是相比论文的重大优势。

**为什么这个方向更有希望**：
1. 结构状态持续数十根 bar，标签信噪比远高于单 bar 入场标签
2. BC 实验 AUC 0.84+ 证明多头入场形态可学——而入场本身是 Phase D/E 的子事件，Phase 标签更易学
3. 若模型能提前识别 Phase D 的开始（比 V8 规则提前 1-3 根 bar），可以提前入场，改善持仓成本

**验证实验设计**（§3c，下一优先级）：
- 从 V8 回测日志导出每根 bar 的 `phase_tag`
- 用 OHLCV 序列训练 Phase 分类器
- 指标：Phase 识别 F1 score（多分类）
- 关键问题：识别 Phase D/E 的 F1 > 0.7？若是，相比 V8 规则提前几根 bar？
