# Agent Prompts (Minimal)

## 通用开发
```text
请先阅读 TASK_NEW/TASKS_with_checklist.md、主策略文件和本次相关模块。
先总结：当前默认值、当前阶段（P1/P3/P4/P5）、风险点、最小改动方案。
然后再实施改动。
要求：
- 不破坏当前默认基线
- 不引入前视偏差
- 高风险逻辑优先加开关
- 先给验证计划，再改代码
```

## P1 参数系统工程
```text
请按 P1 流程处理 [参数/方案名]。
要求：
- 固定所有非 P1 变量
- 本轮只改一个关键参数
- 不做组合爆炸
验证顺序：
1. 先看 gate 分布
2. 再看交易行为
3. 最后看绩效
输出：
- 基线与实验组对比
- 机制解释
- 是否进入下一轮淘汰制
```

## P3 波段级 E/R
```text
请按 P3 要求实现或审查 [改动]。
要求：
- 先确认 P1 是否完成或已有冻结基线
- 使用已有 WaveAnalyzer
- 与 bar 级 E/R 增量融合，不覆盖原逻辑
- 优先作用于减仓 / 退出 / Spring 增强
- 不直接做新的硬入场门槛
输出：
- 改动位置
- 如何影响持仓管理
- 全量与三段回测对比
```

## P4 审查
```text
请审查 [P4 / regime-aware 方案] 是否值得推进。
要求：
- 先定位计算链与接线路径
- 判断是当前主线问题，还是 future optimization 预埋点
- 无明确 regime 失配证据时，不推进接线
输出：
- 已计算 / 已接线 / 暗特性
- 接线后的回归风险
- 结论：推进 / 暂缓 / 归档
```

## P5 / P5-WS
```text
请按 P5 / P5-WS 思路补齐 [ledger / 周报 / 漂移诊断 / 参数治理]。
要求：
- 优先做可统计、可诊断、可提案层
- 不要做 AI 直接改生产参数
- 明确这次改动属于观察层 / 分析层 / 提案层 / 治理层
输出：
- 新增字段 / 输出格式
- 后续 AI 可以基于这些数据做什么
- 哪些边界仍由人工把关
```
