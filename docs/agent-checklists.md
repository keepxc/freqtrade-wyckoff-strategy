# Agent Checklists (Minimal)

## 开工前
- [ ] 已读 `TASK_NEW/TASKS_with_checklist.md`
- [ ] 已确认任务属于 P1 / P3 / P4 / P5
- [ ] 已确认当前默认值和基线
- [ ] 已确认验收口径
- [ ] 已确认是否需要开关 / 回退路径

## 改代码时
- [ ] 改动最小且集中
- [ ] 无前视偏差 / 未来函数
- [ ] informative / HTF 合并仍安全
- [ ] metadata / signal_quality / entry/exit 字段链未断
- [ ] 默认行为未被偷偷改变
- [ ] 若属 P5，不存在 AI 直接改生产逻辑

## 验证前
- [ ] 使用 `user_data/config_backtest.json`
- [ ] 命令带 `--cache none`
- [ ] 已判断是否需要三段回测
- [ ] 已明确重点指标，不只看收益率

## 验证后
- [ ] 记录收益率、交易数、胜率、Sharpe、SQN、最大回撤
- [ ] 对比基线而非只看单次结果
- [ ] 说明改善来自哪里
- [ ] 标注风险或恶化段落
- [ ] 若是参数实验，补机制解释

## P1 专项
- [ ] 冻结非 P1 变量
- [ ] 只改一个关键参数
- [ ] 先看 gate 分布
- [ ] 再看交易行为
- [ ] 最后看绩效

## P3 专项
- [ ] 已有 P1 基线
- [ ] 使用 `WaveAnalyzer`
- [ ] 增量融合，不覆盖 bar 级 E/R
- [ ] 优先影响减仓 / 退出 / Spring 增强

## P4 专项
- [ ] 先审查，不先接线
- [ ] 已确认是否存在 regime 失配证据
- [ ] 仍把环境层视作授权 / multiplier / 熔断层

## P5 / P5-WS 专项
- [ ] 优先补 ledger / 周报 / 漂移诊断 / 参数治理
- [ ] 自动提案 ≠ 自动上线
- [ ] 保留人工最终批准
- [ ] 样本不足时不推进自动调参
